# VES College Attendance System

A MERN-stack attendance management website demo for Vivekanand Education Society (VES) College.

## Stack
- MongoDB
- Express.js
- React.js
- Node.js
- CSS

## Initial Features
- Student attendance dashboard
- Mark Present / Absent
- Attendance percentage
- Student and class views
- Responsive college-focused UI

## Project Structure

```text
Demo-Attendance/
├── client/
│   └── React frontend
├── server/
│   └── Express + MongoDB backend
└── README.md
```

> This repository is a demo project and is not an official VES College system.
